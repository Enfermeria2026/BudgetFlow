Paso 1: Tu situación actual

Bienvenido a BudgetFlow. Para que el sistema funcione correctamente, necesitamos establecer la base de tus finanzas.

El día en el que sueles cobrar tu nómina o ingreso principal (1 al 31). Será tu aviso de nuevo ciclo.

¿De cuánto dinero dispones actualmente sumando tu cuenta del banco y efectivo?

Por favor, rellena los fondos totales con un importe mayor a 0 y un día válido.

Paso 2: Gastos Fijos (Categorías)

El presupuesto base cero exige que le des un trabajo a cada euro. Las Categorías representan tus gastos fijos (alquiler, luz, compra...).

Es obligatorio crear al menos una categoría ahora para aprender cómo funciona. El dinero que le asignes como "Presupuesto Máximo" pasará a estar RETENIDO para asegurar que no te lo gastes en otra cosa.

Paso 3: Huchas de Ahorro

Las huchas sirven para meter dinero que NO PODRÁS GASTAR. Ideal para ahorrar para una casa, un coche o un viaje.

Cualquier aporte inicial que introduzcas se marcará como RETENIDO para protegerlo. Debes tener fondos disponibles suficientes para el aporte inicial.

Paso 4: Fondos Reservados

Útiles para pagos puntuales que sabes que llegarán (seguro del coche, averías, impuestos). El dinero que introduces queda RESERVADO para ese fin.

Paso 5: Todo listo

Así funciona tu panel de control:

  • Fondos Totales: Todo el dinero que tienes en realidad.
  • Fondos Retenidos: El dinero protegido dentro de tus presupuestos, huchas y reservas.
  • Fondos Disponibles: El dinero "libre" que te queda para gastar en imprevistos o crear nuevas huchas.
